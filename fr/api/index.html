En quatre étapes

  1. 1
    Créez votre clé depuis votre compte (titulaire ou membre de l’équipe). Elle est liée à votre fonds et à vos crédits.
  2. 2
    Collez-la dans n8n, Make, Zapier (en-tête Authorization: Bearer …), dans un Custom GPT ou dans Claude via MCP.
  3. 3
    Appelez GET /v1/me pour voir votre fonds, votre plan et vos crédits, puis les endpoints ci-dessous.
  4. 4
    Les appels payants annoncent leur coût (?dry_run=true, en-tête X-Credits-Cost) et répondent 402 avec les packs si le solde manque.

Claude, Cursor, Windsurf (MCP)

Un serveur MCP expose 20 outils en langage naturel : « Passe ces dix sites au crible pour mon fonds », « Écris la LOI du mémo Atelier Morvan », « Quel est mon solde ? ». Le serveur transmet votre clé : il ne peut faire que ce qu’elle autorise.

{
  "mcpServers": {
    "proplace": {
      "url": "https://alexandre-79537--sourcing-agent-fastapi-app.modal.run/mcp",
      "headers": { "Authorization": "Bearer VOTRE_CLE" }
    }
  }
}

ChatGPT, n8n, Make, Zapier

Custom GPT : importez le schéma openapi.json avec une authentification Bearer. n8n / Make / Zapier : un nœud HTTP avec l’en-tête Authorization. Les appels longs (mémos, ajout de cibles) répondent 202 avec un poll_url à interroger toutes les 60 secondes.

Scopes d’une clé : funds, screen, memos, patch, approach, enrich, export. Quotas par défaut : 60 requêtes / min et 1 000 / jour (300 et 10 000 en Standard, 1 000 et 50 000 en Entreprise).
